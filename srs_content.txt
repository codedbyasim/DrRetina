1. Introduction
1.1 Purpose
This Software Requirements Specification (SRS) document defines the complete functional and non-functional requirements for RetinAgent, an AI-powered Diabetic Retinopathy (DR) detection and diagnostic agent. This document is intended for developers, hackathon judges, and stakeholders evaluating the system.
1.2 Project Overview
RetinAgent is an end-to-end intelligent diagnostic system that combines a fine-tuned Vision Transformer (ViT-MAE) model with an LLM-powered agentic layer. The system accepts retinal fundus images as input and produces a DR grade classification (0-4), visual explainability heatmaps, and a natural language diagnostic report. The entire system runs on AMD Instinct MI300X GPUs via AMD Developer Cloud using ROCm.
1.3 Scope
RetinAgent covers the following functional scope:
Retinal fundus image upload and preprocessing
DR grading using fine-tuned ViT-MAE model (Grades 0-4)
GradCAM-based visual explainability overlays
AI-powered natural language diagnostic report generation
Interactive Q&A agent for clinical follow-up questions
Hugging Face Spaces deployment for live public demo

2. System Overview
2.1 Problem Statement
Diabetic Retinopathy (DR) is a leading cause of preventable blindness worldwide. Early and accurate detection is critical but faces two major challenges:
Label Scarcity: Expert grading of retinal images is expensive (approximately $5-$10 per image). Supervised-only models require thousands of labeled images.
Domain Shift: Models trained on data from one hospital fail when deployed at hospitals using different camera equipment, due to texture bias in CNNs.
Interpretability Gap: Clinicians cannot trust black-box models without visual explanations of the diagnosis.
2.2 Proposed Solution
RetinAgent addresses these challenges through a three-component architecture:

ViT-MAE (facebook/vit-mae-base) fine-tuned on APTOS 2019

2.3 Why Fine-tuning Instead of Training from Scratch
The system uses transfer learning rather than full pre-training for the following reasons:
Facebook's ViT-MAE model has already been pre-trained on 1.28 million images and understands universal visual features including edges, textures, and spatial relationships.
Fine-tuning on APTOS 2019 (3,662 labeled retinal images) takes 2-3 hours on AMD MI300X instead of days/weeks for full training.
Total AMD Developer Cloud compute cost is approximately $15-20, well within the $100 credit limit.
Domain-invariant features from MAE pre-training help reduce the domain shift problem inherent in DR detection.

5.2 Model Architecture
5.2.1 ViT-MAE Backbone
Base model: facebook/vit-mae-base from Hugging Face Hub
Architecture: 12 transformer encoder blocks, 768 hidden dimensions, 12 attention heads
Input: 224x224 retinal image divided into 16x16 patches (196 tokens total)
Pre-trained feature: Global self-attention allows model to correlate optic disc with peripheral hemorrhages
5.2.2 Classification Head
Architecture: Linear(768, 256) -> ReLU -> Dropout(0.3) -> Linear(256, 5)
Output: 5 logits corresponding to DR Grades 0-4
Loss function: Weighted Cross-Entropy to handle class imbalance (Grade 4 is rare)

5.3 Data Architecture
5.3.1 Dataset: APTOS 2019
Total images: 3,662 labeled retinal photographs
Classes: Grade 0 (1,805), Grade 1 (370), Grade 2 (999), Grade 3 (193), Grade 4 (295)
Split: 80% training (2,929), 10% validation (366), 10% test (367)
Augmentation: RandomHorizontalFlip, RandomVerticalFlip, RandomRotation(30), ColorJitter
5.3.2 Preprocessing Pipeline
Circle crop: detect fundus boundary using thresholding, crop to bounding box
CLAHE enhancement: clip_limit=2.0, tile_grid_size=(8,8) to improve vessel visibility
Resize: interpolate to 224x224 using bilinear interpolation
Normalize: ImageNet statistics (mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])

Sign up for AMD AI Developer Program to unlock $100 credits
Provision AMD Instinct MI300X GPU instance via AMD Developer Cloud portal
